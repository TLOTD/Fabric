# How to contribute to TLOTD.

You made a port to another version of the Game / another Modlauncher?
- We'll gladly add that as a new branch after an in-depth reviw.

You are able to speak more than one language?
- You are free to submit a translation if you like, help is always appreceated.
- A list of current translations can be found here: [Translations](https://github.com/tlotd/Fabric/tree/1.20.1/src/main/resources/assets/tlotd/lang)

You were able to fix some messy code?
- Thats wonderful, let's see if nothing breaks we might add that to the main branch.
